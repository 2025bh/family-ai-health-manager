# 第二轮功能与 UI 改版实施记录

日期：2026-08-11
项目：FamilyCare AI 家庭健康管家 V0.1（家医 · 小智健康管家）
范围：复盘文档 P1 中的四项功能 + 全站 UI 美化

## 一、结论

四项功能全部落地并真实验收通过；检查资料从"只存不看"升级为"缩略图 + 点击看原图"，不会造成网站流畅度降低。全站样式重做，视觉从米黄老式卡片改为现代清爽的绿色系设计。

后端自动测试 31 项通过（原 24 + 新增 7），前端生产构建通过。本轮没有删除任何文件。

## 二、功能一：最近7天健康摘要

- 新增后端服务 `backend/app/services/weekly_summary.py`：按固定口径汇总最近 N 天日志与测量。
- 分类：睡眠、胃肠与排便、精力、体重、血压、血糖、情绪、口腔、遗精/性健康、用药变化、其他记录。一条记录可同时进入多个类别（例如当天既讲睡眠又讲排便）。
- 新增接口 `GET /api/members/{member_id}/weekly-summary?days=7`。
- 首页新增"最近7天健康摘要"区块，随成员切换刷新；无记录时给出引导提示。

## 三、功能二：时间线筛选

- 个人健康主页时间线新增三组筛选：按类型（全部/健康日志/测量/就医/任务/检查资料/中药）、按时间（全部/最近7天/最近30天）、"只看需要提醒医生的异常"。
- 时间线视觉改为垂直时间轴：彩色圆点区分记录类型 + 左侧连接线，比原来整条色块更易扫读。

## 四、功能三：资料原图预览（性能方案）

回答"原图预览会不会卡"：列表不直接加载原图就不会卡。采用行业标准做法：

- 上传图片时后端自动生成 WebP 缩略图（宽高 ≤ 420px，约几十 KB），存到 `data/uploads/thumbs/`，文件名按规则推导，**不改数据库**。
- 列表页只显示缩略图（`loading="lazy"` 懒加载），16 张真实资料缩略图共约 90KB。
- 点击缩略图弹出大图查看原图（一次只加载一张）；PDF 显示文件卡片，点击新标签打开。
- 新增接口：`GET /api/documents/{id}/file`（原图，带长缓存）、`GET /api/documents/{id}/thumbnail`（缩略图，按需生成，老资料首次访问自动补）。
- 资料页同时支持按类型筛选（化验单/处方/影像/医嘱单/其他）和中文标题。

## 五、功能四：看医生报告生成前核对

- 对话答完 8 个问题后不再直接生成报告，状态变为 `REVIEWING`，提示"先核对清单"。
- 新增核对清单接口 `GET /api/visits/{visit_id}/review`：8 个问题答案 + 近 14 天原始记录分类 + 已知健康问题 + 长期用药 + 近期敏感症状（含遗精等，避免遗漏）。
- 新增确认接口 `POST /api/visits/{visit_id}/confirm`：家属逐项核对后点"确认无误，生成正式摘要"，状态变为 `READY`；重复确认返回 409。
- 就医摘要页自动区分：REVIEWING 显示核对页，READY 显示正式摘要和打印按钮。

## 六、UI 美化

- 重构 `frontend/src/styles.css`：冷白浅绿渐变背景、白色圆角卡片 + 细边框 + 轻阴影、墨绿渐变主色、琥珀强调色。
- 顶栏毛玻璃效果、品牌圆点标识；首页 Hero 柔和渐变卡片。
- 摘要卡片按类别带彩色顶条；时间线彩色圆点；筛选胶囊按钮；资料卡片悬浮上浮；大图预览居中弹窗。
- 保留并适配全部旧页面（设置、中药疗程、任务、联系家人等），响应式与打印样式不变。
