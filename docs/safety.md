# 医疗安全边界（V0.2）

- 独立 `MedicalSafetyLayer`，兼容入口为 `SafetyService`，不依赖系统 Prompt 或大模型自由判断。
- 红旗语义同时判断对象、时间、否定、恢复、他人、假设、提问和转折。
- 他人症状不会写入当前家庭成员；假设句和纯提问不会写成当前症状。
- 风险结果只允许 `insufficient_data / green / yellow / red`；红色升级动作由版本化规则控制。
- 不诊断、不处方、不建议停药或自行改剂量。
- 可能紧急时停止普通聊天，提示联系家人/医疗机构。
- 当前紧急短语只是开发期保守示例；生产使用前必须由医疗专业人员审核。
- `ai_inferred` 只能展示为推测，不能变成确定事实。
- 修改用药/医生记录、拨号、发送重要信息、删除健康记录必须二次确认。V0.1 不提供删除接口。
- 中医健康守护即使开启，也必须先经过统一医疗安全层；中医模块不能降低、延迟或隐藏现代医学红旗提醒。
